# Aviso sobre estas fuentes

Las fuentes de esta carpeta reconstruyen el prototipo **hasta las Fases 0 a 3**. Si vuelves a construir desde estas fuentes, perderás esos cambios. Usa el HTML de la raíz como fuente de verdad.
